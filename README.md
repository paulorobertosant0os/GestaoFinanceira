💰 Gestão Financeira Pessoal (C#)

Projeto de terminal simples desenvolvido em C# e .NET para treinar lógica de programação e Orientação a Objetos.

⚡ O que faz?
* Cadastra receitas e despesas
* Exibe saldo atualizado e histórico de transações
* Trata erros simples de digitação

🛠️ Tecnologias
* C# / .NET
* Conceitos de POO (Classes, Interfaces e Listas)

🚀 Como rodar
```
git clone https://github.com/paulorobertosant0os/GestaoFinanceira.git
dotnet run
```
